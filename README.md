# ⚡ Vite Mastery: Accelerated Learning Path

A comprehensive, hands-on guide to mastering Vite, modern build tooling, and the Cloudflare ecosystem — designed for developers who want to learn fast and build faster.

---

## 🎯 What Is This Course?

This is an **accelerated training program** that takes you from Vite fundamentals to production deployment on Cloudflare's edge network. Through creative analogies, real-world examples, and hands-on exercises, you'll understand not just *how* to use Vite, but *why* it exists and *when* to choose it.

**Total lessons:** 8 comprehensive modules  
**Estimated time:** 15-20 hours (including practice)  
**Prerequisites:** Basic JavaScript/TypeScript and React knowledge

## 🎓 Teaching Philosophy

This course uses **creative analogies** and **visual diagrams** to explain complex concepts:

- **Restaurant Kitchen** — Webpack cooks the entire menu, Vite cooks only what you order
- **House Building** — CRA is a sealed mystery box, Vite is transparent LEGO
- **Car Engine** — Vite is the engine, meta-frameworks (Nuxt, SvelteKit) are the full car
- **Space Mission** — Development is the launchpad, production is space where every byte matters

Each lesson includes:
- 🎯 **Learning objectives** — What you'll know by the end
- 🏗️ **Analogies & diagrams** — Visual understanding
- 🔧 **Code examples** — Ready-to-use patterns
- ⚡ **Quick reference cards** — For daily use
- 📚 **Homework** — Hands-on practice

## ⚡ Quick Reference

### Essential Commands

```bash
# Create project
npm create vite@latest my-app -- --template react-ts

# Development
npm run dev              # Start dev server
npm run dev -- --host    # Expose to network

# Production
npm run build            # Build for production
npm run preview          # Preview production build locally

# Cloudflare deployment
npm install -g wrangler
wrangler login
wrangler pages deploy dist
```

### Essential Config (`vite.config.ts`)

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { '@': '/src' }
  },
  server: {
    port: 3000,
    proxy: { '/api': 'http://localhost:8080' }
  }
})
```
